# Pneumonia Classifier

This project uses transfer learning (MobileNetV2) to classify chest X-rays as normal or pneumonia.

## Features
- Data loading and augmentation
- Transfer learning and fine-tuning
- Evaluation and confusion matrix

## How to Run
1. Install requirements
2. Open the notebook
3. Run cells in order

## Requirements
- TensorFlow
- scikit-learn
- matplotlib
- PIL
